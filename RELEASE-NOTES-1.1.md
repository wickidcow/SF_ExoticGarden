# ExoticGarden Legacy 1.1

**ExoticGarden Legacy 1.1** is the all-in-one modernization release for the
classic ExoticGarden addon.

This update combines API compatibility, storage safety, natural-generation
hardening, event cleanup, cross-fork Slimefun compatibility and CI regression
protection into one release while intentionally preserving classic gameplay
and existing world data.

Highlights:

- Slimefun Legacy-first compatibility.
- Shared Slimefun4 API strategy for Slimefun4, United and Gugu compatibility.
- No GuizhanLibPlugin/GuguSlimefunLib requirement.
- Paper 26.2 / Java 25 modernization.
- Synchronous, chunk-safe natural plant/tree generation.
- Correct world-border center/radius handling.
- Modern world-height scanning.
- Configurable natural generation.
- ExoticGarden block piston protection.
- Centralized BlockStorage compatibility boundary.
- Modern Paper material/particle/effect APIs.
- Stronger GitHub Actions regression checks.
- Exact output: `ExoticGarden-Legacy-1.1.jar`.

All existing ExoticGarden IDs, recipes, plants, foods, tree identities,
schematics and plugin data-folder identity are intended to remain unchanged.
